# 免费活着 / Living for Free

> **技术提高上限，文明抬高下限。**
> 
> **——王正阳**

《免费活着》不是一本教人如何成功的书。

它关心的是另一件事：

**一个普通人，即使没有那么成功，能不能仍然稳定、有尊严地活着。**

---

## 大苹果

《免费活着》提出问题。

**[大苹果社区 / Big Apple LiveOS](https://github.com/meixiaoqiu/bigapple-liveos)** 把这些问题拿到现实里试。

我们正在尝试把住房、能源、任务、资源、协作、规则和风险，逐渐变成一套可以运行、记录、仿真、验证和修改的生活系统。

人仍然自己运行自己的人生程序。

**但底层的一部分麻烦，由系统处理。**

---

这不是答案。

这是一场正在进行的实验。
